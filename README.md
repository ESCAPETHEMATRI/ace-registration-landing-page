# Registration landing page

A responsive, static HTML/CSS landing page based on the supplied reference image.

## Deploy on Vercel

1. In Vercel, choose **Add New → Project** and import this GitHub repository.
2. Select **Other** as the framework preset.
3. Leave the build command empty and use the repository root as the output directory.
4. Deploy.

The `CLAIM NOW` link is configured in `index.html`. Update its `href` if the offer destination changes.
